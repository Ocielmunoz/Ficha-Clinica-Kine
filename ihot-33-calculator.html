iHOT-33 (Cuestionario de Cadera)

International Hip Outcome Tool para Pacientes Jóvenes/Activos

📌 Indicación Clínica

Utilizado para evaluar síntomas y función en pacientes de 18 a 60 años con patología articular de cadera (Pinzamiento Fémoroacetabular, lesiones del labrum, displasia). Es fundamental para decidir manejos conservadores vs. quirúrgicos (artroscopia) y para monitorear el Return to Sport.

Interpretación de Resultados

El puntaje total es el promedio de todas las respuestas marcadas, representado como un porcentaje de 0 a 100%.

  • 100%: Función óptima, asintomático.
  • > 85%: Excelente función. Umbral sugerido para alta deportiva post-artroscopia.
  • 50% - 84%: Disfunción moderada. Limitación en alta demanda.
  • < 50%: Disfunción severa. Calidad de vida afectada significativamente.

Diferencia Clínicamente Importante Mínima (MCID): 6.1 puntos.

Instrucciones para el Paciente

"Estas preguntas buscan saber cuánta dificultad le causa su cadera. Deslice el marcador en la barra para indicar su respuesta considerando el último mes.

El extremo izquierdo (0) indica el peor escenario (dolor extremo o imposibilidad) y el derecho (100) indica el mejor escenario (sin dolor ni dificultad). Si una actividad no aplica a usted, déjela en el centro."
